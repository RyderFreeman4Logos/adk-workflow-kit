# ADR-0007: Skills are instructions and resources, not authority

- Status: Accepted
- Date: 2026-08-09
- Source: [Proposed ADR G](../planning-pack/18_INITIAL_ARCHITECTURE_DECISIONS.md)

## Decision

Integrate Agent Skills but compute permissions by intersection.

## Reason

`allowed-tools` is descriptive/experimental and a Skill may be untrusted or customer-authored.

## Consequence

Activation cannot expand the compiled capability set.
