# ADR-0011: Producer and reviewer sessions are isolated

- Status: Accepted
- Date: 2026-08-09
- Source: [Proposed ADR K](../planning-pack/18_INITIAL_ARCHITECTURE_DECISIONS.md)

## Decision

Use independent session IDs and read-only reviewer tools by default.

## Reason

Reduce context contamination and privilege.

## Consequence

Necessary context is passed as explicit artifacts/inputs.
