# ADR-0006: Network denied by default

- Status: Accepted
- Date: 2026-08-09
- Source: [Proposed ADR F](../planning-pack/18_INITIAL_ARCHITECTURE_DECISIONS.md)

## Decision

No egress unless a workflow/node policy names an approved network profile.

## Reason

Skill scripts and model-generated actions must not exfiltrate data or fetch uncontrolled dependencies.

## Consequence

Connectors should often run as registered brokered tools outside the script sandbox.
