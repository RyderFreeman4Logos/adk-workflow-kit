# ADR-0016: CLI is thin over libraries

- Status: Accepted
- Date: 2026-08-09
- Source: [Proposed ADR P](../planning-pack/18_INITIAL_ARCHITECTURE_DECISIONS.md)

## Decision

Parsing, compilation, execution, testing, and packaging live in reusable crates.

## Reason

CodeSeek, Verbatim, servers, and future GUI need embedding.

## Consequence

No important behavior exists only in shell command handlers.
