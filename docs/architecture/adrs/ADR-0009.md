# ADR-0009: Objective validators outrank model reviewers

- Status: Accepted
- Date: 2026-08-09
- Source: [Proposed ADR I](../planning-pack/18_INITIAL_ARCHITECTURE_DECISIONS.md)

## Decision

Deterministic checks are authoritative, run before publish and after repair.

## Reason

Model reviewers are probabilistic, self-biased, and inconsistent.

## Consequence

A reviewer `pass` cannot waive a failed validator.
