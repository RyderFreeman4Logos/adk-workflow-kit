# ADR-0008: Skill scripts are declared by ID

- Status: Accepted
- Date: 2026-08-09
- Source: [Proposed ADR H](../planning-pack/18_INITIAL_ARCHITECTURE_DECISIONS.md)

## Decision

Execute only scripts listed in a locked runtime manifest through a sandbox.

## Reason

Preserve agility without exposing arbitrary shell.

## Consequence

Script path/hash/runtime/schema/capabilities are package metadata; stable scripts should graduate to Rust.
