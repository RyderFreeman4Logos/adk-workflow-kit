# ADR-0005: Per-run workdir and verified sandbox

- Status: Accepted
- Date: 2026-08-09
- Source: [Proposed ADR E](../planning-pack/18_INITIAL_ARCHITECTURE_DECISIONS.md)

## Decision

Each run has an independent directory and a backend whose enforceable capabilities satisfy the workflow policy.

## Reason

Reproducibility, cleanup, customer isolation, and safe Skill scripts.

## Consequence

Backend mismatch is a preflight error; local process execution is not automatically production-safe.
