# ADR-0018: No hidden chain-of-thought persistence

- Status: Accepted
- Date: 2026-08-09
- Source: [Proposed ADR R](../planning-pack/18_INITIAL_ARCHITECTURE_DECISIONS.md)

## Decision

Store observable events, actions, artifacts, usage, and digests, not private reasoning text.

## Reason

Privacy, security, and unnecessary dependency on hidden model internals.

## Consequence

Replay is structural and artifact-based.
