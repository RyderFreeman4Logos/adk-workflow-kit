# ADR-0025: Freeze ADK-Rust 2.1.0 as the production pin

- Status: Accepted
- Date: 2026-09-02
- Source: Issue #223

## Decision

The production dependency is the exact workspace pin `adk-rust = "=2.1.0"`.
New graph, guardrail, checkpoint, interrupt, and tool-event work uses that
released surface through `workflow-adk`. Do not add a second integration path.

Rejected alternatives:

- Stay on 1.0.0. That is a downgrade. GOV-002 recorded the 1.0.0 baseline
  before the workspace moved to 2.1.0; it is not the production pin.
- A 1.0/2.1 compatibility adapter. YAGNI. The workspace already compiles
  against 2.1.0, and a second adapter would duplicate `AdkGraphTranslator`.

## Reason

ADR-0023 isolated 2.1.0 graph ownership in a spike until the workspace-wide
upgrade. That upgrade is now the committed pin. Keeping 1.0 or wrapping it
would preserve a dead version and a second scheduler.

## Consequence

Issue #223 evidence is the focused probe `just adk-2-1-probe`. It exercises
parallel super-steps, conditional routes, bounded cycles, typed reducers,
checkpoint/resume, HITL interrupt/resume, tool-call events, and guardrail
interception on 2.1.0. Four production workflows are out of scope.
