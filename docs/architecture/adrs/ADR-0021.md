# ADR-0021: Multi-reviewer disagreement defers by default

- Status: Accepted
- Date: 2026-08-24
- Source: [Issue #49](https://github.com/RyderFreeman4Logos/adk-workflow-kit/issues/49)

## Decision

A deterministic, bounded reducer resolves multiple reviewer verdicts for one
subject: the candidate is accepted only when every verdict is `pass`.
Disagreement, any blocking verdict, or any abstention defers. The reducer
reuses the existing `workflow_review` verdict and defect contracts; no second
review engine, live model caller, or policy framework is introduced.

## Reason

Review disagreement is unresolved doubt. Fabricating acceptance from a
majority is a fail-open risk, and non-deterministic arbitration would make
review outcomes unreproducible. A fail-closed default keeps the existing
producer→validator→reviewer→reviser cycle bounded and auditable.

## Consequence

Callers receive an explicit `accept`/`defer` disposition from
`resolve_disposition`, plus typed errors for an empty reviewer set or mixed
subject identity. `defer` returns the candidate to the review cycle; only a
unanimous `pass` on one subject accepts it.
