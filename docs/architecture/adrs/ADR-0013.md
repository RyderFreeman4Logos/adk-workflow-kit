# ADR-0013: Domain source truth remains in applications

- Status: Accepted
- Date: 2026-08-09
- Source: [Proposed ADR M](../planning-pack/18_INITIAL_ARCHITECTURE_DECISIONS.md)

## Decision

Platform artifacts, sessions, auth, and RAG do not replace CodeSeek/Verbatim authoritative stores or ACLs.

## Reason

Preserve security and product semantics.

## Consequence

Application adapters validate every crossing.
