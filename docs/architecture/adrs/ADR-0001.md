# ADR-0001: Build above ADK-Rust rather than another agent framework

- Status: Accepted
- Date: 2026-08-09
- Source: [Proposed ADR A](../planning-pack/18_INITIAL_ARCHITECTURE_DECISIONS.md)

## Decision

Use the latest stable ADK-Rust 1.x as the substrate.

## Reason

Rust requirement, broad stable primitives, existing use in CodeSeek/Verbatim, and avoidance of hand-written agent/runtime machinery.

## Consequence

Direct ADK imports are concentrated in a compatibility layer; upgrades require parity suites.
