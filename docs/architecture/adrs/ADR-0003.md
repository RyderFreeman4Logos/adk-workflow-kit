# ADR-0003: TOML is the first authoring format; canonical IR is authoritative

- Status: Accepted
- Date: 2026-08-09
- Source: [Proposed ADR C](../planning-pack/18_INITIAL_ARCHITECTURE_DECISIONS.md)

## Decision

Parse TOML into a format-neutral IR.

## Reason

Rust ecosystem fit and future JSON/YAML/visual compatibility.

## Consequence

Runtime never executes TOML directly; normalization and hashing are mandatory.
