# ADR-0012: Large stage outputs become artifacts

- Status: Accepted
- Date: 2026-08-09
- Source: [Proposed ADR L](../planning-pack/18_INITIAL_ARCHITECTURE_DECISIONS.md)

## Decision

Use handles and paginated reads rather than copying large values through state/model context.

## Reason

Token cost, memory, provenance, and reuse.

## Consequence

Artifact identity and retention are core runtime contracts.
