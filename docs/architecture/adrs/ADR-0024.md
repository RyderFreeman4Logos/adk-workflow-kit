# ADR-0024: Do not create a companion recipes repository

- Status: Accepted
- Date: 2026-08-29
- Source: Issue #187

## Decision

No companion repository is created for M2-02. The planning-pack gate is not
met because this checkout is not currently consumable as a path-independent
kit:

- the root `Cargo.toml` is a workspace manifest, not a published crate;
- `workflowctl` and `workflow-testkit` consume sibling crates through `path`
  dependencies;
- the current manifests contain no exact git revision pin that a downstream
  consumer can use as the kit entry point.

Keep the executable recipes and decision evidence in this repository. Do not
create a companion GitHub repository until the kit is consumable through a
published crate or an exact git revision pin and a downstream dogfood run can
exercise `run/resume/inspect/replay` using local-only gates.

## Future creation gate

If the prerequisites become true, a follow-up decision must verify the
following before creating anything:

- pin `adk-rust = "=2.1.0"` exactly;
- keep ADK implementation types out of project contracts;
- do not fork ADK internals; file core defects in this repository;
- do not add hosted CI or GitHub Actions;
- retain executable downstream evidence for the four dogfood commands and
  local-only gates.

## Consequence

The no-create decision avoids a second package/release surface while the
workspace still relies on internal path dependencies. The existing workspace
and its local hooks remain the source of truth; reconsider only after the
published-or-pinned consumer boundary and downstream evidence exist.
