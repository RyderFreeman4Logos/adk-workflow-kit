# ADR-0010: All review and correction cycles are bounded

- Status: Accepted
- Date: 2026-08-09
- Source: [Proposed ADR J](../planning-pack/18_INITIAL_ARCHITECTURE_DECISIONS.md)

## Decision

Use explicit max revisions plus global limits and no-progress detectors.

## Reason

Prevent infinite loops, cost surprises, and oscillation.

## Consequence

Exhaustion returns typed abstention/incomplete/failure.
