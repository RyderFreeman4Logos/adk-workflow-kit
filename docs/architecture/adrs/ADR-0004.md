# ADR-0004: Closed node and route sets

- Status: Accepted
- Date: 2026-08-09
- Source: [Proposed ADR D](../planning-pack/18_INITIAL_ARCHITECTURE_DECISIONS.md)

## Decision

v0.1 supports enumerated node kinds and route operators plus versioned registered Rust predicates.

## Reason

Avoid an unsafe, weakly typed second language.

## Consequence

Unsupported logic must be a registered node/predicate or remain handwritten ADK graph code.
