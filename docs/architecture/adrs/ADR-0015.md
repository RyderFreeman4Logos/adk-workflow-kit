# ADR-0015: Extract with characterization tests

- Status: Accepted
- Date: 2026-08-09
- Source: [Proposed ADR O](../planning-pack/18_INITIAL_ARCHITECTURE_DECISIONS.md)

## Decision

Generic CodeSeek behavior is characterized before movement; Verbatim contracts are tested before adapter integration.

## Reason

Avoid silently changing security, cost, or failure semantics.

## Consequence

Framework API freeze waits for three dogfood workflows.
