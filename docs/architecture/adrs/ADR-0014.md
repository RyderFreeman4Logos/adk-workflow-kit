# ADR-0014: Exact stable dependency pins and committed lockfiles

- Status: Accepted
- Date: 2026-08-09
- Source: [Proposed ADR N](../planning-pack/18_INITIAL_ARCHITECTURE_DECISIONS.md)
- Acceptance note: [GOV-002 ADK-Rust baseline](../GOV-002_ADK_RUST_BASELINE.md) already satisfies this decision with the exact `adk-rust =1.0.0` pin, selected features, committed lockfile policy, and MSRV 1.94.0.

## Decision

Deployable workspaces use exact ADK 1.x pins and commit `Cargo.lock`.

## Reason

Reproducible agent behavior and controlled upgrades.

## Consequence

Upgrades are dedicated PRs with parity and conformance tests.
