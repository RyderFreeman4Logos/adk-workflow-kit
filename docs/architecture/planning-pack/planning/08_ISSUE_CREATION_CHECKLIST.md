# Issue Creation Checklist

- [ ] All subagent reports read and cross-reviewed.
- [ ] Current ADK-Rust stable and `main` reverified.
- [ ] Repository name, visibility, owner, and license selected.
- [ ] ADR conflicts resolved.
- [ ] Seed issues deduplicated and right-sized.
- [ ] Every leaf issue has acceptance criteria and tests.
- [ ] Every general ADK feature has upstream analysis.
- [ ] Every side-effect issue describes idempotency/approval.
- [ ] Every sandbox issue names enforceable capabilities.
- [ ] Dependency DAG has no cycles.
- [ ] Priorities assigned after dependency analysis.
- [ ] Epics, labels, and milestones created first.
- [ ] Created issue URLs verified before retrying any failed action.
- [ ] Only unblocked leaf issues added to Hermes Todo.
- [ ] Final planning report distinguishes executed from proposed actions.
